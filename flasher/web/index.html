MeshCore repeater flasher

Puts MeshCore's repeater firmware on a ProMicro nRF52840 (a "faketec") and sets it up, over its USB cable, from this page.

1 The board

Plug in one board with a data USB cable, then choose it. Close any other program that might be using it.

4 Radio

Changing any value switches to Custom. The radio settings take effect when the board restarts, which this page does at the end.

5 Regions

Ticking a region ticks the ones it's in; unticking one unticks the ones inside it. Flood is allowed in each.

6 Additional admin identities

These are public keys given admin on every repeater you flash: for example a monitoring system (like a MeshCore monitor's identities) or other admins. They're kept only in this browser; nothing is sent to the server.

Untick one to leave it off this repeater. Anyone else already on the repeater's admin list is removed, so the ticked ones are the only admin identities. (Logging in with the admin password still works.)

    Sent only to the board, over USB. It isn't saved, shown or sent anywhere else. Up to 15 characters.
